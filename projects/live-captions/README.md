## Contents and setup

- Python microphone/Vosk transcription helper
- TouchDesigner caption builder
- Windows startup and connection-test commands
- Setup and troubleshooting guide

**Requirements:** Windows x64, Python 3.11 recommended, TouchDesigner, microphone, and first-run internet access to install Vosk/sounddevice and download a model.

**Current limits:** Local prototype. Windows microphone and native TouchDesigner checks remain setup-dependent. English is the default; captions are not guaranteed accurate. No radio recordings, speech model, or third-party packages are bundled.
