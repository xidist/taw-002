## Contents and setup

- Mouth_Wah_Mini_Builder.py
- Project setup guide and parameter documentation

**Requirements:** TouchDesigner, a webcam, audio interface, NumPy and the separately installed MediaPipe TouchDesigner plugin. OpenCV is optional for the overlay.

**Current limits:** Source/prototype edition. No native VST3 or DAW plugin is included. Simulated control/DSP checks are documented; live routing and tracking depend on your setup.
