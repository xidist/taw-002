## Contents and setup

- Python hand tracking and OpenCV reference compositor
- TouchDesigner GLSL shader and localhost RGB/control bridge
- Optional OSC controls, setup guide, reference screenshots and validation notes

**Requirements:** Python, OpenCV, MediaPipe and NumPy; TouchDesigner for the GLSL route.

**Current limits:** Eight automated checks passed. Live webcam and native TouchDesigner testing remain pending. No .toe or .tox binary is included.
